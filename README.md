# 💜 Personal Portfolio Website

A modern, responsive portfolio website showcasing my technical skills, projects, research publications, certifications, and educational background in Artificial Intelligence and Machine Learning.

## ✨ Features

- **Modern UI:** Dark theme with purple accents.
- **Projects Showcase:** Project cards with descriptions, technology tags, live demos, and source code links where available.
- **Skills Section:** Skills organized by categories and proficiency levels.
- **Publications:** Research work and conference information.
- **Certifications:** A dedicated section to showcase certifications.
- **Education:** Academic qualifications and achievements.
- **Contact Section:** Links for professional communication.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Frontend Library:** React.js
- **Programming Languages:** TypeScript, JavaScript
- **Styling:** CSS
- **Version Control:** Git and GitHub
- **Code Editor:** Visual Studio Code

## 🚀 Getting Started

### Prerequisites

Install the following before running the website:

- Node.js
- npm
- Git

### Installation

Clone your portfolio repository:

```bash
git clone YOUR_PORTFOLIO_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd YOUR_PORTFOLIO_FOLDER
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the following URL in your browser:

```text
http://localhost:3000
```

### Production Build

To create a production build, run:

```bash
npm run build
```

To start the production server after building:

```bash
npm run start
```
